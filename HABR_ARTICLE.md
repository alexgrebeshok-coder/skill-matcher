# Skill-Matcher для Claude Code: автоматический подбор навыков для AI-агента

![Claude AI Skills](https://habrastorage.org/getpro/habr/upload_files/ai_header.png)

Разбираемся, как проект [alexgrebeshok-coder/skill-matcher](https://github.com/alexgrebeshok-coder/skill-matcher) упрощает управление навыками Claude Code. Сравниваем с альтернативами и показываем, почему это полезно для команд, работающих с AI-агентами.

## Введение

В 2025 году Anthropic представила официальный фреймворк **Agent Skills** — систему расширения возможностей Claude через специализированные навыки. Каждый навык — это набор инструкций в формате Markdown, который Claude загружает при необходимости.

Проблема: когда навыков много (документы, код, дизайн, коммуникации), пользователю нужно помнить, какой навык для чего, и вручную его вызывать. А если забыл название? Или не знаешь, что такой навык вообще существует?

**Skill-Matcher** решает эту проблему — он автоматически анализирует ваш запрос и рекомендует подходящие навыки.

## Что такое Skill-Matcher?

**Skill-Matcher** — это мета-навык для Claude Code, который работает как интеллектуальный диспетчер. Он:

1. **Анализирует первое сообщение** в сессии
2. **Классифицирует задачу** по категориям (документы, код, дизайн и т.д.)
3. **Рекомендует релевантные навыки** с объяснением, почему они подходят
4. **Активирует выбранный навык** после подтверждения пользователя

### Ключевая особенность: умная фильтрация

Skill-Matcher не спамит рекомендациями. Он показывает их только когда это действительно нужно:

| Показывает рекомендацию | НЕ показывает |
|-------------------------|---------------|
| "Создай презентацию о продукте" | "Привет, как дела?" |
| "Заполни PDF форму" | "Что такое REST API?" |
| "Сделай MCP сервер" | "Исправь опечатку в README" |

## Как это работает на практике

### Сценарий 1: Задача с существующим навыком

```
Пользователь: Создай презентацию о нашем новом продукте

Claude: 💡 Для этой задачи подходит скилл **pptx**. Активирую его.

        [Начинает создание презентации с использованием
         специализированных инструкций для PowerPoint]
```

### Сценарий 2: Нет подходящего навыка

```
Пользователь: Помоги настроить мониторинг Kubernetes

Claude: 🔧 Для этой задачи нет готового скилла.
        Могу создать новый с помощью skill-creator —
        он будет доступен для будущих задач. Создать?
```

Skill-Matcher предлагает создать новый навык только если задача:
- Повторяемая (вы будете делать её снова)
- Требует специфического workflow
- Связана со специализированной областью

Для одноразовых задач Claude просто выполняет работу без лишних вопросов.

## Архитектура решения

Skill-Matcher работает через стандартные механизмы Claude Code:

```
~/.claude/
├── CLAUDE.md                    # Автозапуск при каждой сессии
└── plugins/marketplaces/
    └── .../skills/
        └── skill-matcher/
            ├── SKILL.md         # Основная логика матчинга
            └── references/
                ├── skill-catalog.md      # Каталог навыков
                └── external-sources.md   # Внешние источники
```

### Как работает автозапуск

Файл `~/.claude/CLAUDE.md` содержит инструкции, которые Claude читает при старте каждой сессии:

```markdown
# Auto Skill Matching

При начале каждой сессии автоматически анализируй первое сообщение
пользователя и рекомендуй подходящие скиллы.

Формат рекомендации:
💡 Для этой задачи подходит скилл **[name]**. Активирую его.
```

Это **prompt-based решение** — никакого дополнительного кода или сервисов. Вся логика живёт в Markdown-файлах, которые Claude интерпретирует.

## Сравнение с альтернативами

### 1. Встроенный механизм Claude Code (Native)

Claude сам анализирует описания всех навыков и выбирает подходящий.

**Плюсы:** Работает из коробки, понимает сложные переформулировки.
**Минусы:** Требует загрузки метаданных всех навыков в контекст. При большой библиотеке (>15 навыков) это может быть медленно.

### 2. OpenSkills

Универсальный загрузчик навыков для разных IDE (Cursor, Windsurf, Aider).

**Плюсы:** Кроссплатформенность.
**Минусы:** Нет автоматического выбора — просто загружает навыки в систему.

### 3. Roo Commander (бывший Skill Matcher and Delegator)

Мощный оркестратор проектов с ролевой моделью.

**Плюсы:** Умеет переключать роли (PM, Engineer, Analyst) в зависимости от этапа.
**Минусы:** Сложная настройка, высокий порог вхождения.

### 4. Hooks (Claude Code)

Детерминированная активация на основе событий (открытие файла, изменение директории).

**Плюсы:** Мгновенная активация, нулевой расход токенов.
**Минусы:** Работает только для событий файловой системы, не для текстовых запросов.

## Установка

### Вариант 1: Через Plugin Marketplace (рекомендуется)

```bash
# Добавить маркетплейс
claude plugin marketplace add alexgrebeshok-coder/skill-matcher

# Установить плагин
claude plugin install skill-matcher@skill-matcher-marketplace
```

### Вариант 2: Ручное клонирование

```bash
# Клонировать репозиторий
git clone https://github.com/alexgrebeshok-coder/skill-matcher.git

# Скопировать навык в папку Claude Code
cp -r skill-matcher/skills/skill-matcher \
    ~/.claude/plugins/marketplaces/anthropic-agent-skills/skills/
```

### Настройка автозапуска

Добавьте в `~/.claude/CLAUDE.md`:

```markdown
# Auto Skill Matching

При начале каждой сессии автоматически анализируй первое сообщение
пользователя и рекомендуй подходящие скиллы.

Формат рекомендации:
💡 Для этой задачи подходит скилл **[name]**. Активирую его.

Не показывай рекомендацию если:
- Задача тривиальная и не требует специального скилла
- Пользователь просто задаёт вопрос или ведёт разговор
- Нет чёткого соответствия категории
```

## Почему это полезно?

### Для команд с большой базой регламентов

В компаниях с высокой документированностью (строительство, консалтинг, медицина) накапливаются десятки специализированных инструкций. Skill-Matcher помогает:

1. **Не забывать о навыках** — система сама напомнит, что для задачи есть готовое решение
2. **Онбординг новичков** — не нужно изучать всю библиотеку навыков, система сама подскажет
3. **Консистентность** — команда использует одинаковые подходы к типовым задачам

### Для индивидуальных пользователей

- Быстрый доступ к нужному инструменту
- Обнаружение навыков, о которых забыли
- Возможность создавать новые навыки для повторяющихся задач

## Заключение

Skill-Matcher — это простое, но мощное решение для управления навыками Claude Code. Оно не требует дополнительной инфраструктуры, работает через стандартные механизмы Markdown-инструкций и легко расширяется под специфические нужды команды.
